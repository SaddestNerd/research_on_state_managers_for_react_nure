# Единый тестовый модуль

Одинаковый протокол измерений для шести версий приложения.

- `shared/benchCore.js` — сам модуль (идентичен во всех версиях, лежит в `src/bench/` каждого проекта).
- `adapters/` — адаптеры: по одному файлу на версию, связывают пять операций корзины с её менеджером состояния.
- `apply_bench.py` — подключает модуль к проекту (добавляет `src/bench/` и одну-две строки в `index.js` / `App.js`).
- `builds/` — production-сборки шести версий с подключённым модулем.
- `bench-server.js` — сервер: раздаёт сборки (порты 4101–4106), отдаёт каталог из локального снимка, ведёт расписание прогонов и пишет результаты в `results/*.jsonl`.

- `run-headless.js` — автоматический запуск серии без участия человека: поднимает `bench-server.js` и отдельный headless Chrome (свой временный профиль), следит за зависаниями (перезапуск Chrome, после трёх неудач прогон помечается failed).
- `analyze.js` — обработка: медиана, квартили, среднее ± 95 % ДИ, критерий Краскела–Уоллиса, попарные Манна–Уитни с поправкой Холма, сводный рейтинг. Пишет `summary.json`, `summary.csv`, `memory-curves.csv`, `report.md` в папку результатов.

## Автоматический запуск (рекомендуется)

    node run-headless.js            полный протокол (~5 ч), результаты в results/
    node run-headless.js --quick    сокращённый протокол (~7 мин), results-quick/
    node analyze.js                 обработка results/ (или: node analyze.js results-quick)

Опции `--fast N --mem60 N --mem300 N --out DIR` передаются серверу; `--headed` — видимое окно вместо headless.

## Пересборка версии

Сборка обязательно с `REACT_APP_API_URL=/`, иначе приложение обращается к живому API, а не к локальному снимку каталога (`cache/`):

    $env:REACT_APP_API_URL='/'; $env:GENERATE_SOURCEMAP='false'; npm run build
    затем скопировать build/ в bench/builds/<версия>/

## Ручной запуск

    node bench-server.js

затем открыть в Google Chrome `http://localhost:4100/start` и не сворачивать вкладку.
Серия идёт сама: 30 быстрых прогонов на версию, затем 5 × 60 с и 5 × 300 с тестов памяти.
Если серию прервать, повторный запуск продолжит с места остановки.

Модуль неактивен, пока страница открыта без параметра `?bench=...`.
