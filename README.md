# Порівняльний аналіз швидкодії стейт-менеджерів у React

Цей репозиторій є практичною частиною дипломної роботи на тему дослідження ефективності сучасних методів управління станом у веб-додатках.

Додаток реалізовано для проведення бенчмарк-тестів різних бібліотек State Management. **Зверніть увагу: детальні результати вимірювань (час рендерингу, кількість оновлень тощо) виводяться безпосередньо в консоль браузера.**

## 🧐 Про проект

Метою розробки є отримання об'єктивних метрик продуктивності при роботі з великими масивами даних та частими оновленнями інтерфейсу.

Додаток дозволяє:
1. Генерувати навантаження на інтерфейс (рендеринг списків, складні обчислення).
2. Порівнювати поведінку різних стейт-менеджерів в однакових умовах.
3. Отримувати точні дані про час виконання операцій (JS execution time) через консоль.

## 🛠 Стек технологій

- **Core:** React, TypeScript / JavaScript
- **Build Tool:** Vite (або Create React App)
- **State Managers:** Redux Toolkit, MobX, Zustand, Context API, xState
- **Monitoring:** `console.time` / `console.timeEnd`, Performance API

## 📊 Як проводити тестування
Для отримання результатів виконайте наступні дії:
Відкрийте інструменти розробника (DevTools):
Натисніть F12 або Ctrl + Shift + I (Windows/Linux).
Натисніть Cmd + Opt + J (macOS).
Перейдіть на вкладку "Console" (Консоль).
У додатку оберіть стейт-менеджер, який хочете протестувати.
Натисніть кнопку запуску тесту (наприклад, "Start Benchmark").
Дивіться результати в консолі: там з'являться дані про час виконання операцій (ms), кількість ререндерів та інше.
